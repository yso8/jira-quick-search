# 🔍 Jira Quick Search - Extension Chrome

Extension Chrome légère et professionnelle pour accélérer vos recherches de tickets Jira Cloud.

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![Chrome](https://img.shields.io/badge/Chrome-Manifest%20V3-green)
![License](https://img.shields.io/badge/license-MIT-orange)

---

## ✨ Fonctionnalités

- 🔎 **Recherche ultra-rapide** : Recherchez vos tickets Jira directement depuis la barre d'extension
- 🎨 **Material Design** : Interface moderne et intuitive avec Materialize CSS
- 🔒 **Sécurisé** : Authentification via token API (stockage chiffré)
- ⚡ **Performant** : Pas de base de données locale, recherches en temps réel via API REST
- 🌓 **Thème adaptatif** : Support automatique du mode sombre/clair
- 📱 **Responsive** : Fonctionne parfaitement sur tous les écrans
