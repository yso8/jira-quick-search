# Sécurité

Ne publiez pas de token Jira, de capture contenant des données sensibles ou de détail exploitable dans une issue publique. Contactez le mainteneur par un canal privé avec la version, les étapes de reproduction et l’impact observé.

- Utiliser un token API dédié et limité au besoin réel.
- Ne jamais enregistrer un token dans le code source.
- Révoquer immédiatement tout token exposé.
- Vérifier les permissions du compte Jira utilisé.
