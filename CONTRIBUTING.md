# Contribuer

1. Créer une branche dédiée.
2. Décrire le comportement attendu.
3. Tester l’extension dans Chrome avec un compte Jira de test.
4. Exécuter `.\scripts\validate-extension.ps1` et `node --check` sur les fichiers JavaScript.
5. Garder les commits ciblés et documentés.

Avant une proposition, vérifier la configuration, la recherche, les filtres, la pagination, le récapitulatif et les exports. Aucun token réel ne doit apparaître dans le diff.
